# 연습은행 — 은행 앱 연습하기

지적장애 학생이 모바일 은행 앱 사용을 안전하게 연습할 수 있는 가상 은행 웹앱입니다.
진짜 돈과 진짜 개인정보를 쓰지 않으며, 실제 은행과 관계가 없습니다.

## 연습할 수 있는 것

- 계좌 만들기 (이름 → 약관 동의 → 신분증 확인 → 비밀번호 만들기)
- 돈 넣기 (입금)
- 돈 보내기 (송금): 받는 사람 고르기 / 계좌번호 직접 쓰기
- 적금 만들기, 예금 만들기, 만기·해지 체험 ("한 달 뒤로 가기")
- 거래 내역 보기
- 미션 8단계, 금융 안전 퀴즈

## 지원 기능

- 쉬운 말 안내와 음성 읽어 주기 (🔊)
- 다음에 누를 단추 반짝이기 (힌트) — 설정에서 끄면 평가용으로 사용
- 금액을 한글로 함께 표시 (예: 5,000원 → 오천 원)
- 기록은 각 기기의 브라우저에만 저장 (서버 전송 없음)

## 사용 방법

`index.html` 파일 하나로 동작합니다. 브라우저에서 열거나 GitHub Pages로 배포하면 됩니다.
